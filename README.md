Проект "Звёдные Войны"

СТЕК: Angular v22, RxJs, TypeScript, CSS (БЕМ)
Архитектурный подход Feature-based architecture, приложение разделено на самостоятельные бизнес-сущности

Используется открытый API от SWAPI TECH (https://swapi.tech/)
В данном сервисе недостаточно информации, поэтому данные пришлось дополнять руками
Перед запуском приложения нужно включить VPN

node v26+

Start:
  npm start / ng serve
