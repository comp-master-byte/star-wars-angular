# Звёздные войны

Pet-проект на Angular: каталог вселенной «Звёздных войн» с авторизацией, настройками внешнего вида и личным кабинетом.

Данные персонажей, фильмов и планет берутся из открытого API [SWAPI Tech](https://swapi.tech/). Часть полей в API неполная, поэтому ответы дополняются на клиенте (картинки, акцентные цвета, локальные маппинги).

> Перед запуском может понадобиться VPN: `swapi.tech` бывает недоступен без него.

## Стек

- Angular 22 (standalone components, signals)
- TypeScript
- RxJS
- CSS (BEM) + часть UI на Tailwind CSS 4
- Vitest / jsdom для тестов

Архитектура: **feature-based**. Фичи лежат в `src/app/features`, общее в `src/app/shared`.

## Требования

- Node.js **v22.22.3+** (CLI проекта требует современный Node; предпочтительно 24+)
- npm 11+
